## Known Limitations

### Current v0.1
- Text-based UI only
- No persistent storage
- Limited network capability
- No multi-user support
- Single-threaded (mostly)
- No plugin system
- No external module loading

### Priority Fixes
1. Add thread-safe operations
2. Implement error recovery
3. Add logging system
4. Improve performance
5. Better terminal compatibility
